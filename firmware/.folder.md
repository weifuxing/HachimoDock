# Firmware source

- `main/` contains the ESP32-P4 runtime, rendering, input and device protocols.
- `components/`, `assets/` and `config/` provide the firmware's build inputs.
- `tools/` contains image, font, built-in component and flash utilities.
- `tests/` contains host and SDK checks for firmware behavior.

See [build and flashing](BUILD.md) for the four R292 release profiles and [device protocol](protocol.md) for the interface with the desktop client.

HD28091 adaptation preserves the supplier initialization, two 500 Mbps DSI data lanes,
20 MHz DPI on v3, RC resets and 15 ms CST328 polling. Pico input pins are shared
by physical sampling and protocol capabilities in `main/pet_p4_input.h`.
