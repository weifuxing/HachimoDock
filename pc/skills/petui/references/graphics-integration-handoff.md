# 组件图形集成与验证

设备和 PetUI 预览使用同源的 C 场景与刚体核心。选择声明前分别核对目标设备实际报告的图形、场景和刚体能力。公共 v1 表面保持原有预算，显式 graphics v2 按自己的配额校验。字段、兼容范围和示例见 [应用表面](app-surface.md)、[图形 v2](graphics-v2.md) 和 [刚体预览](bodies-preview.md)。

场景绑定数量和源图片数量分别计数。图形 v2 最多绑定八个实体，多个实体可以共享一张图集。v1 仍只允许四个绑定。验证时覆盖未知或重复实体、图集边界、源图片配额，以及旧声明在支持新能力的设备上的限制。

确认弹窗暂停刚体推进。继续时从当前帧恢复，避免补跑暂停期间的步数。卸载和替换组件应释放计时器与预览资源。异步加载完成前若预览已取消，直接丢弃结果。

## 验证

在检出目录执行 `node pc/scripts/test-bodies-entrypoint-offline.mjs` 可用 Chromium 检查真实 AppSurface 入口，包括确认暂停、取消、重挂载、替换和延迟加载。可用 `PET_TEST_BROWSER` 指定 Chromium 可执行文件。

媒体镜像切换须检查同锁快照的资源代次，以及 decoder 退役完成前仍持有旧资源。相关生命周期与验证方法见 [媒体资源与事件实现](capability-ext-audit.md) 和 [设备验收](capability-ext-hil.md)。离线预览验证后，还需在目标设备核对帧耗时、资源预算与输入表现。
